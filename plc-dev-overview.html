##

命令清单

/ flowchart
PHASE 1 · ANALYSIS
输入自然语言工位需求，输出 Mermaid 时序图 + 状态迁移图 + 信号清单。 自动识别异常分支（超时/重试/降级），标注 PLC↔PC 握手序列。
/ define-signals
PHASE 2 · DEFINITION
从已确认的流程图中提取所有信号交互点，按命名规范自动生成信号名，建议空闲地址， 输出 CSV 行直接追加到 signals_config.csv。
/ gen-station
PHASE 3 · CODE GEN
基于流程图 + 信号表生成 IStationHandler 实现类，包含心跳检查、信号等待、动作执行 三步循环，自动注入超时/重试/异常处理代码。
/ validate
PHASE 4 · CHECK
6 项全量校验：CSV→代码引用、代码→CSV 存在、地址冲突、方向一致性、 心跳信号存在、触发-结果成对。输出通过/警告/错误分级报告。
/ diag
PHASE 5 · DEBUG
五层逐级排查：L1 物理连接 → L2 连接状态 → L3 心跳信号 → L4 单信号读写 → L5 工位逻辑。每层输出诊断结论和修复建议。
/ scaffold
NEW PROJECT
新项目一键生成 PLC 通信层完整骨架：PlcMonitor + PlcChannel + ConnectionFactory + SignalReader + 配置模板 + IStationHandler 接口。
