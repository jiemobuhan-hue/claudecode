#### 已解决的关键问题

##### 1. SiemensS7Net IpAddress 设置时 DNS 解析异常
- **现象**: `new SiemensS7Net(SiemensPLCS.S1200, "127.0.0.1:102")` 构造时就触发 `SocketException: 不知道这样的主机`
- **原因**: HSL 将 `IpAddress:Port` 字符串整体做 hostname DNS 解析
- **解决**: 用无参构造 + 分别设置 `IpAddress` 和 `Port` 属性

##### 2. OperateResult.CreateFailedResult 调用错误
- **现象**: `throw NotSupportedException` 在调试时频繁进入异常
- **解决**: 改用返回失败结果而非抛异常

##### 3. Dispatcher.BeginInvoke lambda 转换错误 (.NET 4.8)
- **现象**: `CS1660: 无法将 lambda 表达式转换为 Delegate`
- **解决**: 用 `new Action(lambda)` 或提取成命名方法

##### 4. SignalReader lambda 返回类型不匹配
- **解决**: 加 `(object)` cast

##### 5. ModbusTcpNet ReadInt32(string) vs ReadInt32(string, ushort)
- **解决**: 全部用有 length 参数的版本

##### 6. MainViewModel.ConnectAndPollAsync 同步化
- **之前**: `async Task` 方法 + `await _handler.ConnectAllAsync()`（会卡住）
- **之后**: `void` 方法 + `_handler.ConnectAll()`（立即返回）

##### 7. 所有 PLC 连接类添加 5 秒超时
- SiemensConnection、OmronConnection、MitsubishiConnection、ModbusConnection
- 使用 `Task.WhenAny(connectTask, Task.Delay(5000))` 实现超时保护

#### UI 状态
- MainWindow.xaml: 深色主题 (#1E1E1E)，左侧 PLC 列表，右侧 DataGrid
- MainViewModel: DispatcherTimer 每 5 秒刷新 PLC 状态，SignalDisplayItem 支持 IsChanged 高亮
- 当前配置: Omron PLC x2 (9600/9601) + Siemens S7-1200 (102)

#### 遗留/未解决问题

##### 信号值全部显示 null（已定位根因）

**根因 1（致命）：SignalReader 错误检测失效**
- HSL 的 `ReadInt32()` 等方法返回 `OperateResult<T>`。操作失败时 `.Content` 返回 `default(T)`（int=0, bool=false），**不抛异常**
- 当前代码：`case DataTypeEnum.Int: return _plc.ReadInt32(signal.Address).Content;`
- 失败返回 0，不报错，PollingService 的错误检测 `value is string s && s.StartsWith("Error(")` 根本触发不了
- **轮询每次读 0，信号永远不更新**

**根因 2（致命）：RefreshSignals() 破坏 UI 状态**
- `_signals.Clear()` 后重建，所有 `SignalDisplayItem.Value` 初始化为 null
- `OnSignalUpdated` 触发时 `_signals` 可能还没有该 item，导致新建 item 时 `signal.Value=null`

**根因 3：OnSignalUpdated 找不到 item**
- RefreshSignals() 清空后，OnSignalUpdated 触发时新建 SignalDisplayItem，但此时 signal.Value=null

#### 最新计划（已批准但未执行）

**计划文件**: `C:\Users\Admin\.claude\plans\immutable-whistling-penguin.md`

**修复 1: SignalReader — 检查 OperateResult.IsSuccess**
```csharp
case DataTypeEnum.Int:
    var r = _plc.ReadInt32(signal.Address);
    if (!r.IsSuccess) return $"Error({r.Message})";
    return r.Content;
```
所有 16 种 data type 都要加 IsSuccess 检查。

**修复 2: MainViewModel — RefreshSignals() 不再 Clear()**
改为增量更新，只添加缺失的 item，不破坏已有状态。
