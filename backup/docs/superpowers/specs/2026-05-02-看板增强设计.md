# 看板功能增强设计规范

**日期**: 2026-05-02
**项目**: ZenergyBFSI 蓝膜外观检测上位机

---

## 1. 概述

为 `UC_StatesCards` 看板增加进站/出站数据标识、改进柱状图和饼图逻辑，并实现数据库定时刷新。

**核心目标**：
- 柱状图显示最近5小时内每小时的总产量，颜色区分 OK 和 MES NG
- 饼图在视觉引导后显示 NG 类型分布
- 数据从 CellData 数据库实时查询，不保存本地状态

---

## 2. 数据模型

### CellData 表关键字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 电芯码 | string | 主键 |
| 入站结果 | string | "OK" / "NG" (MES判断) |
| MOM查询来料状态 | string | 同入站结果 |
| 视觉检测参数一~六 | string? | 有值=出站，无值=进站 |
| Ng类型1~8 | string | 视觉NG类型（出站时填充） |
| 进站时间 | datetime | 用于按小时分组 |
| 出站时间 | datetime | 用于判断出站状态 |

### 进站/出站判定

```
出站条件：视觉检测参数一~六 任一有值  OR  复投记录
进站条件：视觉检测参数一~六 全部为空  AND  非复投
```

---

## 3. 柱状图逻辑

### 显示规则

- 显示最近5小时内**有数据的时段**
- 每小时堆叠显示：OK(绿色) + MES NG(红色)
- 时间改变时自动更新UI

### 更新触发

| 触发时机 | 条件 | 更新操作 |
|---------|------|---------|
| ProductArrive (来料) | 入站结果 = "OK" | 该小时 OK +1 |
| ProductArrive (来料) | 入站结果 = "NG" | 该小时 MES NG +1 |
| ProductLeadArrive (出站) | 出站完成 | **不增加柱状图数量** |

### 数据来源

```sql
-- 查询最近5小时的时段数据
SELECT 
    DATEPART(HOUR, 进站时间) as Hour,
    SUM(CASE WHEN 入站结果 = 'OK' THEN 1 ELSE 0 END) as OkCount,
    SUM(CASE WHEN 入站结果 = 'NG' THEN 1 ELSE 0 END) as MesNgCount
FROM CellData
WHERE 进站时间 >= DATEADD(HOUR, -5, GETDATE())
GROUP BY DATEPART(HOUR, 进站时间)
ORDER BY Hour
```

## 4. 饼图逻辑

### 显示规则

- 统计所有出站记录的 NG 类型分布
- NG类型来自 Ng类型1~8（视觉检测）
- OK 不出现在饼图中（OK占比 = 100% - 饼图总和）

### 更新触发

| 触发时机 | 更新操作 |
|---------|---------|
| ProductLeadArrive (出站) | 查询该电芯的 Ng类型1~8，追加到饼图统计 |

### 数据来源

```sql
-- 查询出站记录的NG类型
SELECT Ng类型1, Ng类型2, ..., Ng类型8
FROM CellData
WHERE 视觉检测参数一 IS NOT NULL 
   OR 视觉检测参数一 IS NOT NULL
   OR 复投标记 = 1
```

## 5. 记录表逻辑

### 显示规则

- 同时显示进站和出站记录
- 进站/出站标识：通过视觉检测参数是否为空
- 出站记录显示完整NG类型列表
- 进站记录NG类型列为空

### 列定义

| 列名 | 进站显示 | 出站显示 |
|------|---------|---------|
| 电芯码 | ✓ | ✓ |
| 时间 | 进站时间 | 出站时间 |
| 状态 | 进站结果 | 视觉检测结果 |
| NG类型 | -- | Ng类型1~8合并 |

## 6. 刷新机制

### 定时全量查询 + 事件驱动增量更新

```
┌─────────────────┐     5秒定时      ┌──────────────────┐
│   定时器         │ ──────────────→ │ CellData数据库    │
│   (5秒间隔)      │   全量查询      │ 查询最近5小时      │
└─────────────────┘                 └──────────────────┘
                                          ↓
                                   刷新内存数据
                                          ↓
                                   更新柱状图+饼图+记录表

┌─────────────────┐                 ┌──────────────────┐
│ AutoRun         │ ── RecordArrive →│ DashboardService │
│ ProductArrive   │    增量更新      │ 内存数据更新      │
└─────────────────┘                 └──────────────────┘

┌─────────────────┐                 ┌──────────────────┐
│ AutoRun         │ ── RecordExit ─→│ DashboardService │
│ ProductLeadArrive│   增量更新      │ 内存数据更新+饼图 │
└─────────────────┘                 └──────────────────┘
```

### 接口变更

#### DashboardService 新增方法

```csharp
/// <summary>
/// 从数据库加载看板数据（定时全量刷新）
/// </summary>
void LoadFromDatabase();

/// <summary>
/// 记录来料（增量更新）
/// </summary>
void RecordArrive(string code, string momResult, int stationNo);

/// <summary>
/// 记录出站（增量更新饼图）
/// </summary>
void RecordExit(string code, string visionResult, string ngTypes);
```
