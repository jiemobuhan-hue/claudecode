**日期**: 2026-05-13
**类型**: 修改

## 背景

UC_StatesCards 看板 `StartClock()` 中每秒生成随机测试数据，覆盖了 DashboardService 从 SQLite 真实查询的结果，导致看板始终显示假数据。

## 改动

### UC_StatesCards.xaml.cs

1. **删除测试数据生成** — 移除 `StartClock()` 内 `#region 测试数据` 全部代码（~100行），只保留 `TxtClock.Text = DateTime.Now.ToString("HH:mm:ss")` 实时时钟更新

2. **恢复 Messenger 订阅** — 在 `Loaded` 事件中重新注册：
   - `Messenger.Default.Register<DashboardUpdateMessage>` → `UpdateDashboard()`
   - `Messenger.Default.Register<StatusLightUpdateMessage>` → `UpdateStatusLight()`
   - 原因：此前注释掉是因为误以为 UC_Home 已订阅转发，实际上 UC_Home 并未订阅，消息链路断裂

## 生效数据流

```
DashboardWorker (5s定时器, SQLite 12h窗口)
  → DashboardService (Messenger 发送)
    → UC_StatesCards.OnDashboardUpdateMessage
      → UpdateDashboard() → KPI / 柱状图 / 饼图 / DataGrid
```
