## SqlHelper 关键方法说明

SqlHelper 的 `ExecuteNonQuery` 和 `GetDataTable` 方法通过 `cmdType` 参数区分执行类型：
- `cmdType = 1` → 执行 SQL 文本语句
- `cmdType = 2` → 执行存储过程

```csharp
// 调用存储过程的语法
SqlHelper.ExecuteNonQuery(connStr, "存储过程名", 2, SqlParameter数组);
SqlHelper.GetDataTable(connStr, "存储过程名", 2, SqlParameter数组);
```

## 重要发现：int 类型参数问题

**问题描述**：
使用 `SqlHelper` 调用存储过程时，某些 `int` 类型参数会出现"parameter was not supplied"错误，即使参数已经传递。

**原因分析**：
当使用 `new SqlParameter("@NGtypeNum", 0)` 方式创建 int 参数时，params 数组在传递过程中可能丢失该参数。

**解决方案**：
对于 int 类型参数，显式指定 `SqlDbType.Int`：

```csharp
// 显式指定 SqlDbType.Int
var ngTypeNumParam = new SqlParameter("@NGtypeNum", SqlDbType.Int) { Value = 0 };

int rows = SqlHelper.ExecuteNonQuery(CONNECTION_STRING, "Proc_InsertBlueFilmDetection", 2,
    // ... 其他参数
    ngTypeNumParam,
    // ... 其他参数
```
