# 调试日志 2026-05-05

## 问题：X 轴数据问题

### 代码片段分析
```csharp
okSeries.Points.Add(new SeriesPoint(h.Hour, h.Ok));
ngSeries.Points.Add(new SeriesPoint(h.Hour, h.Ng));
```

### 发现的问题
1. **Hour 可能为字符串**：如果是 `"09:00"` 格式，X 轴按字母排序导致显示错误
2. **没有 Clear()**：每次刷新数据会累积而不是替换，可能导致内存泄漏和旧数据显示

### 解决方案
- 如果 Hour 是字符串，需要解析为 int：
  - `int.Parse(h.Hour)` 或
  - `int.Parse(h.Hour.Split(':')[0])`（如果是 "09:00" 格式）
- 推荐方案：修改数据模型让 Hour 直接存 `int` 类型
