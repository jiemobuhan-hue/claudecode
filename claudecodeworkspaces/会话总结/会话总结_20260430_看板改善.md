## 三、消息流程

```
AutoRun.ProductArrive(no=1~4)
    ↓
MOM查询 → MOMRes = "OK" / "NG" / "离线"
    ↓
SQLiteGenericHelper.BulkUpsert<CellData>(...)
    ↓
DashboardService.I.RecordArrive(code, MOMRes, no)
    ↓
累计统计更新
RecentRecords 新增
HourlyData 更新
    ↓
Messenger.Default.Send(StatusLightUpdateMessage)
Messenger.Default.Send(DashboardUpdateMessage)
    ↓
UC_Home.OnStatusLightUpdate() → _dash.UpdateStatusLight()
UC_Home.OnDashboardUpdate()   → _dash.UpdateDashboard()
    ↓
ApplyKpi() → KPI 显示
ApplyNgTypes() → NG饼图
ApplyRecords() → 记录列表
RedrawHourly() → 小时图表
```

## 六、DashboardService 使用说明

### AutoRun 中的调用

**入站记录** (`ProductArrive`):
```csharp
DashboardService.I.RecordArrive(code, MOMRes, no);
// code: 电芯码
// MOMRes: "OK" | "NG" | "离线"
// no: 工位号 1~4
```

**出站记录** (`ProductLeadArrive`):
```csharp
string ngTypes = string.Join("|", new[] { data.Ng类型1, data.Ng类型2, ... }
    .Where(s => !string.IsNullOrEmpty(s)));
DashboardService.I.RecordExit(code, data.视觉检测结果, ngTypes);
// code: 电芯码
// data.视觉检测结果: "OK" | "NG"
// ngTypes: "外观缺陷|尺寸超差" 或空字符串
```

**获取当前数据**:
```csharp
var data = DashboardService.I.GetDashboardData();
```

**重置统计**:
```csharp
DashboardService.I.Reset();
```
