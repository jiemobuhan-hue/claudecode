## 关键代码说明

### 使用存储过程
所有CRUD操作均通过存储过程执行，第二个参数 `2` 表示 `CommandType.StoredProcedure`：
```csharp
SqlHelper.ExecuteNonQuery(_connectionString, "Proc_InsertBlueFilmDetection", 2, parameters);
SqlHelper.GetDataTable(_connectionString, "PROC_GetAllBlueFilmDetection", 2, parameters);
```

### Repository类方法
- `Insert()` / `InsertAsync()` - 插入记录
- `GetAll()` / `GetAllAsync()` - 查询所有记录
- `GetByNum()` / `GetByNumAsync()` - 根据Num查询
- `GetByCellCode()` / `GetByCellCodeAsync()` - 根据电芯码查询
- `GetByPackCode()` / `GetByPackCodeAsync()` - 根据包装码查询
- `Delete()` / `DeleteAsync()` - 删除记录
- `GetCount()` / `GetCountAsync()` - 获取记录总数
