## 代码结构说明

### CCDDataDal.cs 参考模式

```csharp
// 使用SqlHelper.CreateParameters<T>生成参数
List<SqlParameter> listParas = SqlHelper.CreateParameters<CCDDataModel>(ccdData);
return Add(SqlInfoManager.L_sqlConnection[0], InsertProcName, 2, listParas.ToArray());
```

**注意**: `SqlHelper.CreateParameters<T>` 会将属性名首字母小写作为参数名（如 `CellCode` -> `@cellCode`），但存储过程参数通常是原始大小写（如 `@CellCode`），因此对于简单的 Insert 操作仍使用手动参数构造以匹配存储过程签名。
