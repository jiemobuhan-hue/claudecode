数据模型：DefectRegion + 坐标系统

坐标换算逻辑是 Canvas 标注正确性的关键

DefectRegion 类 — 单个缺陷

DefectRegion 字段设计
字段类型说明
DefectIdstring唯一标识，用于复判事件传递
DefectTypestring缺陷类型：划痕 / 凹坑 / 异物 / 气泡 ...

坐标换算公式

从归一化坐标 → Canvas 像素坐标
// 图片原始尺寸
originalW = bitmap.PixelWidth
originalH = bitmap.PixelHeight

// Image 控件实际渲染尺寸（考虑 Stretch=Uniform）
displayW = image.ActualWidth
displayH = image.ActualHeight

// 归一化坐标 → 显示坐标
scale = min(displayW / originalW, displayH / originalH)
offsetX = (displayW - originalW * scale) / 2
offsetY = (displayH - originalH * scale) / 2

rectX = offsetX + defect.X * originalW * scale
rectY = offsetY + defect.Y * originalH * scale
rectW = defect.Width * originalW * scale
rectH = defect.Height * originalH * scale

默认数据策略

GenerateDefaultDefects() — 在视觉数据就绪前的占位方案

在 ImageRecord 中新增静态方法 GenerateDefaultDefects()：

  • 为每张图片生成 1-3 个默认缺陷区域
  • 坐标固定在图片中央区域（如 X=0.3, Y=0.3, W=0.15, H=0.10）
  • 类型随机从 {划痕, 凹坑, 异物} 选取
  • 置信度随机 0.7~0.95
  • 后续替换：改为从 SQL Server 查询视觉检测结果表填充

确认点

1. 坐标格式 — 用归一化 0.0~1.0，与图片分辨率无关。OK？
2. DefectId — 用 GUID 字符串，SQL Server 实际字段名以后对接时再映射。OK？
3. 默认数据 — 放在 ImageRecord.GenerateDefaultDefects()，以后替换为 Repository 查询。OK？
