交互流程

事件链路
1. 打开: 卡片点击 → OpenDefectMap(img) → 显示 GridOverlay → 加载大图 + 绘制 DefectCanvas 矩形 + 绑定缺陷列表
2. 点击缺陷矩形: Rectangle.MouseDown → 高亮该矩形 → 在 DefectDetailContainer 中加载 DefectReviewControl
3. 点击缺陷列表项: 同上，同时滚动大图使该缺陷可见
4. 复判提交: DefectReviewControl.ReviewSubmitted → OnReviewSaved(defectId, ...) → 刷新列表项状态 + 更新 Canvas 矩形样式
5. 切换图片: 上一张/下一张 → 重新调用 LoadDefectMap(nextImg)
6. 关闭: 保留现有关闭按钮逻辑
