命令详解

① flowchart <需求描述> 新项目 / 新工位

输入自然语言需求 → 输出 Mermaid 时序图 + 状态迁移图。覆盖：正常流程、异常分支、超时处理、重试逻辑。用户确认流程图后进入下一步。

/plc-dev flowchart "通道1来料：PLC触发→PC扫码→MOM查单→回写结果。异常：扫码超时3秒重试，MOM不可用走离线队列"
② define-signals 新项目 / 新工位

读取已确认的流程图，自动提取需要哪些 PLC 信号（触发、数据、结果、心跳），按命名规范生成信号名，建议地址分配，输出 CSV 行。支持手动调整后确认写入。

③ gen-code 新项目 / 新工位

基于流程图 + 信号表，生成 IStationHandler 实现代码（CheckHeartbeatAsync → WaitForSignalAsync → ExecuteActionAsync），包括超时、重试、异常分支。已存在的 PLC 连接层直接复用。

④ validate 现有项目

校验：CSV 中每个信号是否都有代码引用 · 代码中引用的信号是否都在 CSV 中 · 地址是否冲突 · 读写方向是否一致 · 心跳信号是否存在。

⑤ diag 现有项目

分层诊断：物理连接 → PLC 心跳 → 单个信号读写 → 工位状态机运行。每层给出检查项和修复建议。

scaffold 全新项目

一键生成 PLC 通信层项目骨架：PlcMonitor + PlcChannel + ConnectionFactory + SignalReader + 配置模板 + 心跳循环。选品牌即生成对应 Connection 实现。
