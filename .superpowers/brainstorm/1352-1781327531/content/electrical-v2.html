PLC 开发技能包 — 重新设计

定位：可复用的上位机-PLC对接开发模板，当前项目作为参考实现

ELECTRICAL.md — 架构模式文档（泛用）

不是"这个项目有什么信号"，而是"一个上位机项目该怎么组织PLC代码"

§1 架构模式

PlcMonitor → PlcChannel → IPlcConnection 三层抽象 · 品牌无关的连接工厂 · 信号读写统一接口 · Rx 推送模式 · 配置驱动 vs 代码驱动

§2 信号定义规范

CSV/JSON 信号表模板 · 命名规范（功能_通道_动作）· 数据类型映射表 · 地址编码规则 · 读写方向约定

§3 工位状态机模式

IStationHandler 接口契约 · 三步循环（心跳检测→信号等待→动作执行）· CTC 协调 · 全局心跳暂停 · 多通道扩展模板

§4 品牌适配指南

Omron FINS / Siemens S7 / Modbus TCP / Mitsubishi Melsec · 各品牌连接参数模板 · 地址格式差异 · 已知限制

§5 模拟与测试

无硬件调试方案 · SimulationMode 模式 · 模拟数据生成器 · PLC 信号模拟器 · 单元测试策略

§6 故障排查

通用诊断流程（连接→心跳→信号→逻辑）· 常见问题速查 · 日志分析 · 抓包调试

/plc-dev 技能 — 开发脚手架命令

命令设计（泛用 + 项目内两种模式）
命令适用场景功能
scaffold 新项目 生成 PLC 通信层项目骨架：连接工厂 + 信号读器 + 配置模板 + 心跳
add-plc 新项目 / 现有项目 引导式新增 PLC 设备：选品牌 → 填 IP → 自动生成配置和连接代码
add-signal 现有项目 引导式新增信号：选 PLC → 选地址 → 命名 → 更新 CSV → 更新代码引用
gen-station 现有项目 基于信号名生成 IStationHandler 工位代码模板：心跳检查 + 信号等待 + 动作执行
validate 现有项目 校验信号配置完整性：CSV 与代码引用一致性 · 地址冲突 · 缺失读写
diag 现有项目 交互式故障排查：连接→心跳→信号→工位 逐层检查
