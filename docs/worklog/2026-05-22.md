### Bug 修复
1. **进站时间格式问题** (`/HH` → ` HH`)：`DateTime.Now.ToString("yyyy/MM/dd/HH:mm:ss")` 导致日期和时间之间是 `/` 而非空格，`DateTime.TryParse` 解析失败 → `QueryHourly` 的 "检测中" 计数恒为 0
2. **SQL 注入/未加引号** (`AutoRun.cs:1552`, `AutoRun.cs:852`)：`WHERE 电芯码 = {code}` 无单引号，纯数字码可工作但 `SIM-...` 字母码被 SQLite 当成列名 → `no such column` 错误
