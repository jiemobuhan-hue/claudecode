# 工作日志 2026-05-25

## 图片加载性能优化

### 新增
- `Service/ThumbnailCache.cs` — BMP→JPEG 缩略图缓存服务
  - 缓存目录: `%LocalAppData%/ZenergyBFSI/thumbcache/`
  - 缓存键: `SHA256(sourcePath|lastWriteTicks|decodeWidth)`，源文件更新自动重建
  - JPEG Q85 输出，`DecodePixelWidth` 参数化
  - 并发锁（`ConcurrentDictionary` + 双检锁），磁盘满回退
- `View/StateCards/UC_InspectionView.xaml.cs` — `BuildImageCards` 重写
  - 占位卡片模式：60 张卡片同步渲染（<100ms），无图片加载
  - 后台 `Task.Run` 逐张加载缩略图，`Dispatcher.InvokeAsync` 渐进替换
  - `CancellationTokenSource` 切换产品时取消旧加载
  - `BuildPlaceholderCard` — 与 `BuildCard` 结构一致的轻量卡片（灰底+角度名）
  - `ReplacePlaceholderImage` — 保留 zoom 按钮，仅替换 TextBlock

### 修复
- `ThumbnailCache`: `decodeWidth` 纳入缓存键
- `ThumbnailCache`: `IOException` 时删除半截文件、返回 null
- `ReplacePlaceholderImage`: `Children.Clear()` → 选择性移除 `TextBlock`，保留 zoom 按钮

### 效果
- 60 张 20MB BMP: 16s 冻结 → <100ms UI + 3~5s 后台渐进
