## 核心修复

### 统计逻辑（TASK-REFACTOR-001）

| 问题 | 修复前 | 修复后 |
|------|--------|--------|
| KPI翻页变化 | total = 当前页500条 | 全窗口 COUNT(*) 聚合 |
| 良率分母 | OK / Total（含进站） | OK / (OK+NG)（仅出站） |
| Hourly OK柱 | 进站记录计为OK | 进站→Pending，出站OK→OK，出站NG→NG |
| 进站判定Badge | 显示"OK" | 显示"检测中"（蓝色） |

### 班次窗口（TASK-REFACTOR-004）

```
全天 "all" → 选定日期 00:00:00 ~ 次日 00:00:00 (24h)
A班  "A"   → 选定日期 08:00:00 ~ 20:00:00 (白班 12h)
B班  "B"   → 前一天 20:00:00 ~ 选定日期 08:00:00 (晚班 12h)
```

- 5秒定时器仍在运行，但窗口固定不变
- 班次/日期切换 → DashboardService.SetFilter → 立即重查 + 重置首页

### 三色时段图（TASK-REFACTOR-005）

堆叠柱从下到上：**检测中（蓝 #2196F3）→ OK（绿 #4CAF50）→ NG（红 #F44336）**

### 模拟数据生成器

```csharp
// 写入 500 条模拟记录（昨天00:00 ~ 今天23:59，48h均匀分布）
SimulationDataGenerator.GenerateAsync(500);

// 清理模拟数据
SimulationDataGenerator.Clear();
```

数据通过 `SQLiteGenericHelper.BulkUpsert` 写入，电芯码格式 `SIM{yyMMddHHmmss}-{序号}`。

## 数据流（当前）

```
SimulationDataGenerator.GenerateAsync()
  → SQLite CellData 表

DashboardWorker (5s定时器, 班次固定窗口)
  → QueryKpi / QueryHourly / ParsePageRecords
  → DashboardSnapshot
  → DashboardService (Messenger)
  → UC_StatesCards.OnDashboardUpdateMessage
  → KPI卡片 / 三色时段图 / NG饼图 / DataGrid
```

班次/日期切换：
```
UC_StatesCards.ShiftRadio_Checked / DpDate_SelectedDateChanged
  → DashboardService.I.SetFilter(shift, date)
  → DashboardWorker.SetFilter(shift, date)
  → 重新计算窗口 + 立即查询
```
